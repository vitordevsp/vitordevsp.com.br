# Template de semente de conteudo

Copie o bloco abaixo dentro de `.journey/seeds/content-seeds.md` para registrar uma ideia reaproveitavel.

```md
## Ideia: Titulo provisorio

### Origem

De qual conversa, decisao, marco ou episodio veio essa ideia.

### Tese

Qual e a ideia central.

### Formatos possiveis

- Post:
- Video:
- Aula:
- Lead magnet:

### Relacao com SDD

Como essa ideia ajuda alguem a entender ou desejar SDD.

### Maturidade

Bruta | Promissora | Pronta para roteiro | Pronta para publicar
```

## Regras de uso

- uma ideia por bloco;
- citar a origem com link relativo (`[EP-003](../episodes/003-...md)` ou data do marco) quando aplicavel;
- marcar maturidade de forma honesta; nao classificar como `Pronta para publicar` sem ter o roteiro mais ou menos claro;
- evitar duplicacao com episodios; uma seed e um plano de conteudo, nao um relato.
