# Legacy: Build Release

## Purpose

Preserve the useful release-closing workflow: define scope, classify impact, and produce a short release note.

## Useful legacy guidance

- Confirm the release scope (what is included and what is not).
- Classify impact (major/minor/patch) based on actual user-facing change.
- Produce a short release note that does not duplicate the entire change list.

## Current Agents Studio interpretation

- Release work is one capability: commit grouping, changelog updates, and version recommendation.
- Always separate “proposal” from “execution” (no automatic publishing).
