# pre-release

Routine para revisar changelog, versão, planos concluídos e riscos antes de publicar, taguear ou comunicar uma release.

## Conhecimentos úteis

- Esta routine é um fechamento de prontidão, não a criação da release inteira.
- Quando a versão candidata for ambígua, o próximo passo deve ser usar `semantic-version-reviewer`.
