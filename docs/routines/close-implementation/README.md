# close-implementation

Routine para fechamento técnico e documental antes de considerar um recorte pronto para commit, encerramento de execução ou transição de contexto.

## Conhecimentos úteis

- Nem todo fluxo recorrente merece ser `skill`; alguns momentos do ciclo funcionam melhor como `routine`.
- O pedido de commit frequentemente carrega uma expectativa implícita de fechamento técnico e documental.
