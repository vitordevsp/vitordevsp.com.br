# finalize-changelog

Routine para revisar e fechar `CHANGELOG.md` antes de release, merge ou publicação.

## Conhecimentos úteis

- Esta routine entra depois de `build-changelog`, não no lugar dela.
- O foco é validar fechamento, clareza e coerência semântica antes de avançar para release.
