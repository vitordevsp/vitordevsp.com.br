## Contexto

`generateNotionPageID` depende do último hífen do slug. Isso quebra ou fica frágil quando o slug não segue o formato esperado, quando o título contém hífens ou quando a entrada já é um ID puro.

## Objetivo

Extrair o ID do Notion a partir dos últimos 32 caracteres hexadecimais, aceitando slug com hífen, slug sem hífen e ID puro.

## Escopo

### Fazer

- Atualizar `src/lib/notion/helpers/utils.ts`.
- Usar regex ou validação de tamanho fixo para localizar ID no final da string.
- Preservar comportamento de callers existentes.
- Documentar exemplos de entradas aceitas se não houver suite de testes.

### Não fazer

- Não criar runner de testes só para esta mudança sem decisão explícita.
- Não alterar formato público das URLs.
- Não mexer no renderer de posts.

## Detalhes técnicos

Direção esperada:

```ts
const NOTION_ID_REGEX = /[0-9a-f]{32}$/i
```

Entradas que devem funcionar:

- `meu-post-aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa`
- `meupostaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa`
- `aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa`

## Critérios de aceite

- [ ] Slug com hífen extrai o ID corretamente.
- [ ] Slug sem hífen extrai o ID corretamente.
- [ ] ID puro continua válido.
- [ ] Entrada inválida falha de forma previsível.
