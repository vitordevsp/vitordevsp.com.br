## Contexto

O client atual não fixa `Notion-Version` e herda o default do SDK. Um upgrade do `@notionhq/client` pode mudar contratos silenciosamente, especialmente em torno de databases e data sources.

## Objetivo

Passar `notionVersion` explicitamente ao construtor do `Client`, registrando a escolha no código de forma curta.

## Escopo

### Fazer

- Alterar `src/lib/notion/client.ts`.
- Fixar uma versão suportada pelo SDK instalado.
- Preferir a versão mais recente compatível, salvo regressão conhecida.
- Registrar comentário curto explicando a intenção de evitar default móvel.

### Não fazer

- Não subir versão do SDK como parte desta tarefa.
- Não migrar databases para data sources aqui; isso é `P002-T007`.
- Não manter uma versão que quebre rotas atuais.

## Detalhes técnicos

Direção esperada:

```ts
import { Client } from "@notionhq/client"

export const notion = new Client({
  auth: process.env.NOTION_TOKEN,
  notionVersion: "2026-03-11",
})
```

`2026-03-11` era a latest no snapshot local da documentação; confirmar compatibilidade com o `@notionhq/client` instalado antes de fechar.

## Critérios de aceite

- [ ] `src/lib/notion/client.ts` passa `notionVersion`.
- [ ] Versão escolhida é compatível com o SDK instalado.
- [ ] Comentário curto explica a escolha.
- [ ] Rotas Notion continuam carregando.
