## Contexto

O jardim usa estágios para comunicar maturidade das notas. A UI deve explicar isso sem virar uma página didática demais nem esconder conteúdo.

## Objetivo

Criar indicativo visual de estágio e card explicativo para notas em estágio inicial.

## Escopo

### Fazer

- Criar `EstagioNota`.
- Criar `CardAvisoEstagio`.
- Suportar `semente`, `broto`, `muda`, `planta` e `arvore`.
- Exibir aviso apenas em `semente`, `broto` e `muda`.
- Definir origem do texto explicativo antes de implementar o link/destino.

### Não fazer

- Não transformar todo card em texto explicativo.
- Não criar novos estágios sem schema.
- Não hardcodar conteúdo editorial se a decisão for Notion.

## Detalhes técnicos

Depende de: `P005-T001`.

Hipótese inicial: textos editoriais do jardim devem morar no Notion porque ele é o CMS público do projeto, mas isso precisa confirmação.

## Critérios de aceite

- [ ] Estágios são renderizados com rótulo claro.
- [ ] Card de aviso aparece só em estágios iniciais.
- [ ] Texto explicativo tem origem definida.
- [ ] Componentes são exportados quando necessário.
