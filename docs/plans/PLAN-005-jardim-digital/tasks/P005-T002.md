## Contexto

O jardim precisa nascer navegável mesmo com dados incompletos. O recorte de subpáginas deve evitar prometer todas as visões editoriais antes do schema amadurecer.

## Objetivo

Criar `/jardim` e as subpáginas iniciais do MVP com navegação clara e estados vazios honestos.

## Escopo

### Fazer

- Criar rota principal em `src/app/(pages)/jardim/`.
- Criar navegação para subpáginas escolhidas no MVP.
- Garantir estados vazios quando houver pouco dado no Notion.
- Evitar hardcode de subpáginas sem schema ou conteúdo.

### Não fazer

- Não implementar todas as subpáginas possíveis por antecipação.
- Não criar busca full-text.
- Não criar página individual de leitura.

## Detalhes técnicos

Depende de: `P005-T001`.

Subpáginas candidatas: marcos, ensaios, trilha, vídeos, posts, padrões e changelog. O MVP deve escolher um subconjunto executável.

## Critérios de aceite

- [ ] `/jardim` renderiza com navegação inicial.
- [ ] Subpáginas do MVP têm rota ou link coerente.
- [ ] Estados vazios não parecem erro.
- [ ] Rotas sem schema definido não são expostas como promessa falsa.
