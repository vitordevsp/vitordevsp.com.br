## Contexto

Cursos em breve precisam de uma UI de interesse, mas a submissão só pode ser real quando o destino dos dados existir.

## Objetivo

Criar `ListaEspera` com campo de email e estados de envio, sucesso e erro, sem simular persistência se o backend ainda não estiver pronto.

## Escopo

### Fazer

- Criar `src/components/frames/ListaEspera/`.
- Implementar campo de email com labels e estados acessíveis.
- Preparar integração com route handler quando `P006-T004` existir.
- Desabilitar ou limitar submissão real se não houver backend.

### Não fazer

- Não salvar email nesta tarefa.
- Não criar API route.
- Não fingir sucesso sem persistência.

## Detalhes técnicos

Depende de: `P006-T001` e `P006-T002`.

## Critérios de aceite

- [ ] Formulário tem campo de email acessível.
- [ ] Estados de envio/sucesso/erro existem ou estão preparados.
- [ ] Sem backend definido, UI não simula persistência.
- [ ] Componente funciona em mobile.
