## Contexto

O route handler cria persistência de dados pessoais. Ele só deve existir depois do destino dos emails ser decidido e precisa validar input no servidor.

## Objetivo

Criar `src/app/api/lista-espera/route.ts` para salvar email, curso e data no destino escolhido com validação server-side e proteção mínima contra abuso.

## Escopo

### Fazer

- Criar route handler apenas depois da decisão de destino.
- Validar email no servidor.
- Registrar curso e data junto da inscrição.
- Aplicar proteção mínima contra abuso compatível com Vercel/serverless.
- Retornar erros claros para o formulário.

### Não fazer

- Não criar API antes de `P006-T001`.
- Não salvar dados sem validação.
- Não implementar automação de marketing.

## Detalhes técnicos

Depende de: `P006-T001` e `P006-T003`.

Se o destino for Notion, documentar banco e propriedades em `docs/product/notion/data-sources.md`.

## Critérios de aceite

- [ ] Route handler existe no caminho definido.
- [ ] Email é validado server-side.
- [ ] Curso e data são persistidos no destino escolhido.
- [ ] Proteção mínima contra abuso está implementada ou limitação está registrada.
- [ ] Formulário trata sucesso e erro reais.
