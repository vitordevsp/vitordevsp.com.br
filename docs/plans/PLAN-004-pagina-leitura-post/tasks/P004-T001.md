## Contexto

Posts vêm do Notion e podem conter parágrafos longos, listas, code blocks, imagens e toggles. A base tipográfica precisa funcionar antes de adicionar sidebar e índice.

## Objetivo

Melhorar conforto de leitura em `/posts/[slug]` ajustando fonte, largura de linha, espaçamento, contraste e blocos renderizados.

## Escopo

### Fazer

- Revisar estilos da área de leitura.
- Validar parágrafos longos, listas, imagens, code blocks e toggles.
- Manter o conteúdo vindo do `PageRenderer`.
- Preservar responsividade.

### Não fazer

- Não criar TableOfContents nesta tarefa.
- Não alterar parser do Notion além do necessário para estilo.
- Não mudar schema de posts.

## Detalhes técnicos

Áreas prováveis: `src/app/(pages)/posts/[slug]/style.scss` e estilos associados ao renderer.

## Critérios de aceite

- [ ] Largura de linha fica confortável em desktop.
- [ ] Espaçamento entre blocos melhora a escaneabilidade.
- [ ] Code blocks, listas, imagens e toggles continuam legíveis.
- [ ] Mobile mantém leitura sem overflow horizontal.

## Referências

- `src/app/(pages)/posts/[slug]/style.scss`
- `src/lib/notion/components/PageRenderer/`
