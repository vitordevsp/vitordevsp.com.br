## Contexto

Depois da base tipográfica, a página precisa de uma estrutura que acomode conteúdo principal e navegação por seções sem depender do modelo futuro de WikiNav.

## Objetivo

Criar ou ajustar um layout de leitura com área principal e sidebar de índice em desktop, com alternativa simples em mobile.

## Escopo

### Fazer

- Ajustar `src/app/(pages)/posts/[slug]/page.tsx` e estilos relacionados.
- Criar `PostLayout` apenas se a extração simplificar a página.
- Reservar espaço para índice lateral.
- Definir comportamento mobile: índice colapsado, antes do conteúdo ou acesso simples equivalente.

### Não fazer

- Não implementar navegação wiki esquerda.
- Não implementar scroll spy.
- Não alterar conteúdo retornado pelo Notion.

## Detalhes técnicos

Depende de: `P004-T001`.

O layout deve assumir duas colunas principais: conteúdo + TOC. Terceira coluna só entra depois de decisão do PLAN-005.

## Critérios de aceite

- [ ] Desktop suporta conteúdo e índice lateral.
- [ ] Mobile tem alternativa clara para o índice.
- [ ] Layout não sobrepõe texto nem reduz demais a leitura.
- [ ] Estrutura permite conectar `TableOfContents` na próxima tarefa.
