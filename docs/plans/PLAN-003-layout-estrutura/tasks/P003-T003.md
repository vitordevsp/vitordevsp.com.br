## Contexto

O footer deve ajudar o usuário a entender o mapa do site. Há intenção de newsletter, mas ainda não há backend ou destino de envio nesta história.

## Objetivo

Reformular `PageFooter` com mapa de navegação e campo visual de newsletter sem simular persistência.

## Escopo

### Fazer

- Atualizar `src/components/frames/PageFooter/`.
- Adicionar links úteis para seções existentes.
- Incluir campo visual de newsletter com comportamento honesto.
- Garantir responsividade e acessibilidade básica.

### Não fazer

- Não implementar backend de newsletter.
- Não criar rota de captura.
- Não fingir envio bem-sucedido.

## Detalhes técnicos

Enquanto não houver destino, o campo pode ficar desabilitado, apontar para contato existente ou ser apresentado como visual/preparatório. A decisão final deve ficar registrada antes da implementação.

## Critérios de aceite

- [ ] Footer lista caminhos relevantes do site.
- [ ] Campo de newsletter não envia dados para lugar inexistente.
- [ ] Estados de foco e leitura por teclado continuam claros.
- [ ] Mobile não quebra com textos longos.
