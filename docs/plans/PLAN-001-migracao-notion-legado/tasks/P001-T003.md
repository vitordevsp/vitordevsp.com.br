## Contexto

A página de vídeos ainda depende do service legacy. A migração precisa trocar a origem dos dados sem mudar o que a UI recebe para renderizar cards, thumbnails e links do YouTube.

## Objetivo

Substituir `videoService.list()` por leitura via `getDatabaseItems<VideoProps>` usando o banco de vídeos da integração moderna.

## Escopo

### Fazer

- Definir ou mover `VideoProps` para o local adequado nesta etapa.
- Atualizar `src/app/(pages)/videos/page.tsx`.
- Ler dados com `process.env.NOTION_DB_VIDEOS`.
- Preservar geração de `thumbnailUrl` e `videoUrl`.
- Criar helper moderno de YouTube se não houver alternativa existente.

### Não fazer

- Não redesenhar a página de vídeos.
- Não mudar schema do banco de vídeos.
- Não remover `_resources/` ainda.

## Detalhes técnicos

Contrato de URL a preservar:

```ts
const thumbnailUrl = `https://i.ytimg.com/vi/${id}/hqdefault.jpg`
const videoUrl = `https://www.youtube.com/watch?v=${id}`
```

Depende de: `P001-T002`.

## Critérios de aceite

- [ ] `src/app/(pages)/videos/page.tsx` não usa mais `videoService.list()`.
- [ ] A página continua exibindo thumbnails e links corretos do YouTube.
- [ ] A leitura usa `NOTION_DB_VIDEOS` com `getDatabaseItems<VideoProps>`.
- [ ] Build não acusa erro de tipo na página de vídeos.
