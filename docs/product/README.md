# Produto

Esta pasta existe como espaco para contexto de produto quando necessario.

Para este projeto (portfólio pessoal e blog), nao ha time de produto ou contratos de API proprios. O conteudo editorial e gerenciado diretamente no Notion.

Se no futuro o projeto ganhar contratos de API ou especificacoes funcionais mais formais, este e o lugar correto para centralizar essas referencias.

## Relacao com o restante da documentacao

- `docs/patterns/` define como o codigo deve ser estruturado.
- `docs/product/notion/` documenta os bancos de dados do Notion como CMS.
- `docs/team/` registra contexto de projeto e ecossistema.
