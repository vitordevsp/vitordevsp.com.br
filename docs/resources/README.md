# Resources

Esta pasta existe para centralizar materiais auxiliares que complementam a documentação principal do projeto, mas não são fonte de verdade de produto, plano, pattern, skill, routine, agent ou contexto de time.

Use esta pasta para guardar ou localizar:

- links úteis;
- referências externas;
- contexto visual ou técnico complementar;
- materiais de apoio que não sejam, por si só, fonte da verdade de uma feature ou fluxo.

Exemplos atuais:

- mapas técnicos auxiliares;
- notas antigas preservadas apenas como contexto;
- materiais complementares de arquitetura.

Contratos de API e histórias de produto ficam em [`../product/`](../product/README.md).

Contexto de time, projeto, ecossistema e ownership fica em [`../team/`](../team/README.md).

## Relação com o restante da docs

- [`../README.md`](../README.md) é o ponto de entrada da documentação.
- [`../patterns/README.md`](../patterns/README.md) explica como construir.
- [`../product/README.md`](../product/README.md) preserva fonte funcional e contratos de produto.
- [`../team/README.md`](../team/README.md) preserva contexto de time e ecossistema.
- `resources/` guarda apenas apoio complementar que não pertence a essas camadas.
