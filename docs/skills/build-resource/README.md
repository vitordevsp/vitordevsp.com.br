# build-resource

Skill para criar, revisar ou evoluir resources estáveis de apoio, como mapas, referências e históricos preservados.

## Conhecimentos úteis

- Resource bom ajuda várias frentes sem competir com pattern, plan, product, team ou memória.
- O maior risco dessa skill é virar uma pasta de “sobras”; por isso o limite do material precisa ficar claro.
- Histórias, critérios e contratos de produto pertencem a `docs/product/`; contexto de time e ecossistema pertence a `docs/team/`.
