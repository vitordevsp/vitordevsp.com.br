# Build Routine

Use esta skill quando a tarefa for criar, revisar ou evoluir uma routine em `docs/routines/`.

## Quando usar

Use esta skill quando:

- o fluxo acontece em um momento específico do ciclo;
- há uma ordem importante de checagem ou passagem;
- o caso não é capacidade ampla o suficiente para virar `skill`;
- o ritual precisa ser reaplicável entre sessões e projetos.

## Leitura obrigatória

1. `docs/routines/README.md`
2. `docs/patterns/taxonomia-framework.md`
3. `docs/patterns/documentacao.md`

Depois, carregue:

- a skill maior relacionada, quando existir;
- o plano da frente, quando houver;
- rotinas já existentes, para evitar duplicação.

## Sequência recomendada

1. Verifique se o caso é realmente `routine` e não `skill`.
2. Defina o gatilho do momento operacional.
3. Estruture a checagem com foco em fechamento, transição ou validação.
4. Crie `ROUTINE.md` e `README.md` na pasta própria.
5. Atualize índices e planos afetados.

## Saída esperada

1. nova routine ou routine evoluída;
2. gatilho explícito do momento operacional;
3. fronteira clara com skills e patterns;
4. documentação de navegação atualizada.

## O que esta skill não deve fazer

- transformar qualquer checklist em routine;
- criar rotina que deveria ser só regra;
- tratar fluxo amplo como se fosse momento situacional.
