# build-routine

Skill para criar, revisar ou evoluir routines quando um fluxo representar um momento situacional do ciclo de trabalho.

## Conhecimentos úteis

- Routine é mais sobre passagem de etapa do que sobre construir algo novo.
- A melhor rotina é curta, clara e acionável perto do momento em que ela realmente importa.
