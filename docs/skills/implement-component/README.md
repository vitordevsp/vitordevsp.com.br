# implement-component

Skill para criar, revisar ou evoluir componentes do projeto com foco em recorte de responsabilidade, estados, comportamento e relação com specs e referência visual.

## Conhecimentos úteis

- Nem todo trecho de UI deve virar componente; o recorte precisa melhorar clareza e manutenção.
- A skill precisa equilibrar responsabilidade funcional e composição visual sem abstração precoce.
