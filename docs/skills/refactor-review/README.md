# refactor-review

Skill para revisar nomes, coesão, duplicação leve e clareza técnica sem abrir uma refatoração ampla.

## Conhecimentos úteis

- Essa skill funciona melhor para saneamento localizado no fim de uma implementação.
- O objetivo não é redesenhar arquitetura, e sim reduzir ruído e melhorar manutenção sem reabrir a frente principal.
