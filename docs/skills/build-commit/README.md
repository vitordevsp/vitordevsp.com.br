# build-commit

Skill para organizar, sugerir e executar commits no padrão do projeto com base no estado atual do Git, no histórico recente e no agrupamento lógico das mudanças.

## Conhecimentos úteis

- O valor desta skill não está só em escrever a mensagem do commit, mas em decidir o corte correto do histórico.
- O histórico melhora quando o corpo do commit registra intenção, contexto e impacto do agrupamento escolhido.
