# build-plan

Skill para criar, revisar ou evoluir planos estruturados em `docs/plans/`, organizando objetivo, contexto, escopo, checklist, log, conhecimentos consolidados e perguntas em aberto.

## Conhecimentos úteis

- Planos úteis precisam sobreviver a várias sessões sem virar dump de ideias.
- A seção de `Conhecimentos consolidados` passou a ser parte importante do valor do plano, não só do seu histórico.
- Planos agora vivem em pastas `PLAN-NNN-descricao/` com `README.md`, começando flat e separando arquivos apenas quando crescerem.
