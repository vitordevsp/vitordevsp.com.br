# build-skill

Skill para criar, revisar ou evoluir outras skills do projeto com base na taxonomia de `docs/`, nas skills já existentes e no aprendizado acumulado da camada.

## Conhecimentos úteis

- Skills boas nascem de repetição real ou claramente previsível.
- A camada de `skills` precisa servir tanto para criação quanto para melhoria de artefatos já existentes.
