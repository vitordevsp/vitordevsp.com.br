# evolve-domain-flow

Skill para criar, revisar ou evoluir um fluxo funcional de domínio cruzando docs vivos, stores, services, pages, components, specs e contratos externos quando existirem.

## Conhecimentos úteis

- A maior parte do trabalho real em produto costuma ser evolução de fluxo existente, não criação do zero.
- Essa skill ganha valor quando preserva a fronteira entre docs vivos, implementação atual e limitações temporárias de contrato.
