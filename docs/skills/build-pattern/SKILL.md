# Build Pattern

Use esta skill quando a tarefa for criar, revisar, absorver, dividir ou consolidar um pattern em `docs/patterns/`.

## Quando usar

Use esta skill quando:

- um tema transversal já apareceu o suficiente para virar regra;
- existe duplicação entre patterns;
- um tema ainda está espalhado entre memória, planos e skills;
- a taxonomia do framework ou do projeto precisa de refinamento.

## Leitura obrigatória

1. `docs/patterns/README.md`
2. `docs/patterns/documentacao.md`
3. `docs/patterns/taxonomia-framework.md`

Depois, carregue:

- patterns vizinhos;
- plano relacionado, quando houver;
- skills ou agents que dependam desse pattern.

## Sequência recomendada

1. Verifique se o assunto é realmente transversal.
2. Descubra a fonte de verdade do tema.
3. Decida se o conteúdo deve nascer, ser absorvido ou ser dividido.
4. Escreva o pattern em formato útil para decisão de implementação.
5. Atualize índices e planos tocados.

## Saída esperada

1. pattern criado ou evoluído;
2. fronteira mais clara entre camadas;
3. índices atualizados;
4. planos com log e conhecimento, quando fizer parte de uma frente.

## O que esta skill não deve fazer

- criar pattern só por preferência editorial;
- transformar regra local e imatura em norma ampla;
- duplicar conteúdo já estável em outro pattern.
