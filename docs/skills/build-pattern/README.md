# build-pattern

Skill para criar, revisar ou evoluir patterns a partir de recorrência real e fronteiras estáveis entre as camadas do framework.

## Conhecimentos úteis

- Pattern bom nasce quando o assunto muda decisão em vários lugares, não só quando o texto fica bonito.
- O maior risco dessa skill é promover cedo demais uma convenção ainda local ou imatura.
