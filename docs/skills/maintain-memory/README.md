# maintain-memory

Skill para criar, revisar ou evoluir memorias locais em diferentes camadas do projeto, como a raiz, `docs/product/notion/` e outros contextos que precisem preservar aprendizado reaproveitavel.

## Conhecimentos úteis

- Memoria local nao e sinonimo de `MEMORY.md` da raiz; ela pode existir em camadas especificas quando isso reduzir ruido e melhorar contexto.
- O principal valor dessa skill e decidir o que permanece como memoria e o que ja deve subir para camada mais estavel.
