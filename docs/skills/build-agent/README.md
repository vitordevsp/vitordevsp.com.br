# build-agent

Skill para criar, revisar ou evoluir agentes especializados em `docs/agents/`, preservando a fronteira entre fluxo recorrente de execução e papel que exige julgamento próprio.

## Conhecimentos úteis

- Nem tudo que parece sofisticado merece virar `agent`; muitos casos continuam melhores como `skill`.
- Um bom agente do projeto nasce quando existe especialização recorrente, e não apenas sequência de passos.
