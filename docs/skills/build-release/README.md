# build-release

Skill para fechar uma release documental, combinando changelog, recomendação de versão e nota resumida do recorte.

## Conhecimentos úteis

- Essa skill faz mais sentido depois que o changelog do recorte já está minimamente confiável.
- Release boa depende de versão coerente, não só de um texto bonito para anúncio.
