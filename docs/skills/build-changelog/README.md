# build-changelog

Skill para criar, revisar ou evoluir `CHANGELOG.md` com base em commits, planos e regras de versionamento.

## Conhecimentos úteis

- O changelog deve registrar mudança histórica relevante, não repetir o git.
- O valor dessa skill cresce quando ela cruza commits com planos e com o impacto público do que mudou.
