# implement-service

Skill para criar, revisar ou evoluir services do projeto com base em patterns de service e tipagem, consumidores reais, docs do domínio e OpenAPI quando aplicável.

## Conhecimentos úteis

- Services concentram muitos riscos de contrato, payload e tratamento de erro, então o fluxo precisa ser cuidadoso.
- Essa skill é mais forte quando trata também saneamento e melhoria de integrações já existentes.
