# implement-page

Skill para criar, revisar ou evoluir pages e rotas do projeto combinando jornada da tela, integrações, specs, referência visual e fechamento documental.

## Conhecimentos úteis

- A page é onde rota, layout, estado e integração se encontram, então a skill precisa cruzar várias camadas.
- O valor dessa skill aumenta quando ela ajuda a melhorar pages existentes, não só criar telas novas.
