# notion-maintain-docs

Skill para manter viva a camada `docs/product/notion/` como adapter específico de Notion, cruzando MCP, memória do domínio, data sources, iniciativas clonadas e referências locais.

## Conhecimentos úteis

- A camada de Notion só continua útil quando conversa com a documentação viva do projeto e não vira camada paralela desconectada.
- Essa skill ganha valor como manutenção contínua, e não só como operação pontual.
- No framework, esta skill deve ser vista como adapter específico, não como regra universal para qualquer ferramenta de gestão.
