# build-specs

Skill para criar, revisar ou evoluir `specs.md` de artefatos reais do projeto combinando código atual, patterns, docs vivos do domínio, contratos e referências visuais quando existirem.

## Conhecimentos úteis

- `build-specs` não serve só para criar specs novas; ela também precisa melhorar specs existentes.
- O código atual e as fontes técnicas reais devem prevalecer sobre documentação defasada.
