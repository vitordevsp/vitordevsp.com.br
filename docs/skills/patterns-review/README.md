# patterns-review

Skill para revisar aderência estrutural, documental e de responsabilidade entre camadas antes de considerar uma entrega bem fechada.

## Conhecimentos úteis

- O valor dessa skill está em detectar desvio de taxonomia e responsabilidade antes que ele se consolide no código.
- Ela funciona melhor como revisão transversal leve, e não como refatoração ampla.
