# build-project-history

Skill para criar, revisar ou evoluir um `project-history.md` com visão, objetivo, funcionamento geral e contexto estrutural de um projeto, módulo ou área relevante.

## Conhecimentos úteis

- `project-history.md` não substitui `plan`, `product-history.md` nem `CHANGELOG.md`; ele ocupa um espaço mais estrutural e relativamente estável.
- Essa skill é especialmente útil quando o contexto do sistema está espalhado entre código, planos, docs vivos e memória oral.
