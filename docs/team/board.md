# Board externo

Este arquivo registra ferramentas externas usadas para acompanhar trabalho deste repositório.

Ele não substitui `docs/plans/`: os planos locais continuam sendo a fonte de verdade para contexto, escopo, decisões e tarefas detalhadas. O board externo existe para coordenação, visualização e acompanhamento operacional.

## Relação com os planos locais

- `docs/plans/` organiza as frentes de trabalho do repositório.
- Issues no Linear devem apontar para o plano local correspondente quando houver.
- Quando uma decisão nasce no Linear e vira regra ou contexto estável, ela deve migrar para o arquivo local responsável.
- Informações sensíveis, credenciais e dados pessoais desnecessários não devem ser registradas aqui.
