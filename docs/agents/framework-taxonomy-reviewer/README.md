# framework-taxonomy-reviewer

Agent especializado em revisar se um artefato está nascendo na camada certa do framework.

## Conhecimentos úteis

- A qualidade da taxonomia depende de recorrência, estabilidade e custo de manutenção, não só do assunto do artefato.
- Esse agent é especialmente útil quando uma frente começa a criar patterns, skills, routines e plans em paralelo.
