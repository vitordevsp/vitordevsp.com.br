# memory-maintainer

Agent especializado em curadoria de memórias locais do projeto, preservando a fronteira entre memória, instruções estáveis, patterns, skills, plans e resources.

## Conhecimentos úteis

- Curadoria de memória é diferente de edição mecânica: ela envolve decidir permanência, promoção, condensação e descarte.
- Esse agent deve continuar agnóstico quanto ao lugar da memória, cobrindo raiz, `docs/product/notion/` e outros contextos locais quando fizer sentido.
