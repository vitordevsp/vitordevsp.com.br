# semantic-version-reviewer

Agent especializado em classificar impacto de release e recomendar versão semântica quando a decisão exigir julgamento mais fino.

## Conhecimentos úteis

- Semver útil depende mais de impacto público real do que de volume de arquivos alterados.
- Esse agent é mais valioso quando a release mistura documentação, fluxo, contrato e ferramenta no mesmo recorte.
